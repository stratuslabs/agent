# Stratus Agent roadmap

The specs for shipped steps of the [v2 architecture](../architecture/stratus-v2.md). Each one is a short spec: goal, why now, scope, design sketch, acceptance criteria, and open questions. They record why things were built the way they were.

Steps 06, 09–11, and 13–14 build the capability ecosystem; the contract they share — plugins, toolsets, tools, skills — is specified once in [`plugins.md`](../architecture/plugins.md).

**Numbers are stable identifiers.** Specs and code comments refer to steps by number, so numbers are never reused, and the gaps belong to steps that are not documented here.

Partly shipped work is documented where it landed rather than as a spec: the container image and system unit in [Deployment](../guides/deployment.md), the per-agent state layout in [State layout](../reference/state-layout.md), and the plugin registration handles in [`plugins.md`](../architecture/plugins.md).
